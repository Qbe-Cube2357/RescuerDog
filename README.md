# Swimming Dog

独自の犬かきコントローラーで犬を操作する体験型ゲームです。東京ゲームショウ2026に出展しました。

このリポジトリでは、ゲームのUnityプロジェクトおよび関連プログラムを管理しています。リポジトリ名は「RescuerDog」ですが、作品名は「Swimming Dog」です。

## 作品概要

プレイヤーはプールを泳ぐ犬を操作し、飼い主が投げ込んだおもちゃを集めます。

独自コントローラーの左右のハンドルを回すことで、犬かきの動きを体感しながら遊べます。ハンドルの動きをセンサーで取得し、ゲーム内の犬の移動に反映しています。

## 使用技術・機器

- **Unity / C#**：ゲーム本編、メニュー画面、外部プログラムとの連携
- **M5Stick**：独自コントローラーの動きを取得するためのセンサー入力
- **画像処理プログラム**：画像処理機能の実装とUnityとの連携

## 自分の担当箇所

### ゲーム本編・メニュー画面
Unityを用いたゲーム本編のプログラミングと、メニュー画面の実装を担当しました。

### センサーとUnityの連携
M5Stickのセンサー値の取得、Unityへのデータ転送、ゲーム内の動作への反映を担当しました。独自コントローラーの動きと、画面内の犬の動きを連携させる仕組みを実装しました。

### 画像処理プログラム
画像処理プログラムの作成と、Unityとの連携を担当しました。

### ビルド
展示用アプリケーションのビルドを担当しました。
